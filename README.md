# My Portfolio

## Project Title
My Portfolio Website

## Overview
A personal portfolio website showcasing my background, skills, and creative works as a Multimedia Arts student.

## Features
- Home page
- About Me page
- Skills page
- Contact page
- Responsive website layout
- Navigation menu
- Contact form validation

## Technologies
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- GitHub
- InfinityFree

## Setup
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using Live Server.
